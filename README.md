# Дипломный проект: Интернет-магазин MEGANO

Финальный индивидуальный проект по курсу «Python-фреймворк Django». В рамках проекта разработан полноценный бэкенд для готового фронтенд-приложения на базе Django и Django Rest Framework (DRF).

## Реализованный функционал
- **Каталог товаров**: двухуровневые категории, фильтрация по цене/тегам/наличию, сортировка и пагинация.
- **Главная страница**: динамические блоки популярных товаров, баннеров и товаров ограниченного тиража.
- **Детальная страница товара**: вывод полной информации и интерактивное добавление отзывов покупателей.
- **Система пользователей**: сессионная авторизация, регистрация (Sign Up) и личный кабинет с редактированием профиля.
- **Корзина и Заказы**: сессионная корзина, многошаговое оформление заказа, фиктивная онлайн-оплата и автоматическое списание остатков товаров со склада при покупке.

## Инструкция по развертыванию проекта

Для успешного запуска проекта на локальной машине выполните следующие шаги:

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python версии 3.10 или выше. Откройте терминал в корневой папке проекта и активируйте виртуальное окружение:

```bash
# Создание виртуального окружения (если не создано)
python -m venv venv

# Активация окружения для Windows (cmd)
venv\Scripts\activate
```

### 2. Установка зависимостей
Установите все необходимые библиотеки из зафиксированного файла `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 3. Применение миграций базы данных
Создайте необходимые служебные и прикладные таблицы в локальной базе данных SQLite:
```bash
python manage.py migrate
```

### 4. Создание суперпользователя (Администратора)
Для доступа к административной панели Django создайте учетную запись администратора:
```bash
python manage.py createsuperuser
```
Следуйте подсказкам терминала (задайте логин и пароль, например `admin` / `admin12345`).

### 5. Запуск сервера разработки
Запустите встроенный веб-сервер Django:
```bash
python manage.py runserver
```

После этого откройте браузер и перейдите по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## Доступ к административной панели
Панель управления магазином доступна по адресу: [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
Используйте данные созданного на шаге 4 суперпользователя для управления категориями, тегами, товарами и просмотра оформленных заказов.
