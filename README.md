# Дипломный проект: Платформа интернет-магазина (Django B2C E-commerce)

Полнофункциональное бэкенд-приложение для интернет-магазина, разработанное на **Django** и **Django REST Framework (DRF)**. Проект реализует сложное серверное API, которое полностью интегрировано с подключаемым клиентским SPA-интерфейсом.

## ✨ Реализованный бэкенд-функционал (API)
- **Каталог и фильтрация:** Роуты для вывода товаров с поддержкой многоуровневых категорий, тегов, сортировки по цене/популярности/отзывам и пагинации.
- **Управление корзиной:** API для добавления, изменения количества и удаления товаров (с корректной обработкой сессий для неавторизованных пользователей).
- **Система заказов и оплаты:** Оформление заказов, валидация остатков на складе, расчет стоимости доставки и интеграция с эмуляцией платежных шлюзов.
- **Личный кабинет пользователя:** Профиль, история заказов, а также система аутентификации.
- **Отзывы и рейтинги:** Добавление пользовательских обзоров к товарам с автоматическим пересчетом среднего рейтинга.

## 🚀 Инструкция по развертыванию проекта

### 1. Подготовка бэкенда
1. Создайте виртуальное окружение и установите зависимости:
   ```bash
   cd diploma-backend
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Выполните миграции базы данных и запустите сервер разработки:
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```

### 2. Подключение фронтенд-пакета
Фронтенд поставляется в виде изолированного django-приложения. Для его сборки и интеграции выполните:

1. Соберите пакет:
   ```bash
   cd ../diploma-frontend
   python setup.py sdist
   ```
2. Установите полученный архив в ваше виртуальное окружение:
   ```bash
   pip install dist/diploma-frontend-X.Y.tar.gz
   ```
3. Убедитесь, что приложение `'frontend'` подключено в вашем `settings.py` в `INSTALLED_APPS`, а его маршруты добавлены в корневой `urls.py`.

После запуска локального сервера по адресу `http://127.0.0` откроется стартовая страница интернет-магазина, полностью работающая на вашем API.
